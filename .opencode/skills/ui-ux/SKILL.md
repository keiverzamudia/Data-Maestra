# UI/UX

## Bandejas
Mostrar:
- código de solicitud;
- artículo;
- solicitante;
- departamento;
- estado;
- fecha;
- responsable;
- prioridad.

## Modal de revisión
Orden:
1. información original;
2. información normalizada;
3. sugerencia de maestro;
4. campos editables;
5. validaciones;
6. historial;
7. acciones.

## Reglas
- No ocultar información crítica.
- Confirmar acciones irreversibles.
- Usar texto además de color.
- Mantener consistencia de estados.
- Diseño responsive.
